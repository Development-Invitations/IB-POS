### Новое в этой версии

- **Подсказки при сканировании, если товар не найден точно** — раньше при сканировании штрихкода, которого нет в вашем каталоге и точно нет в госкаталоге, оставалось только вводить название вручную. Теперь система показывает несколько похожих товаров из госкаталога (штрихкод совпадает не точно, только похож) — можно выбрать нужный одним тапом вместо ручного набора, либо ввести вручную, если ни один не подходит.
