### Новое в этой версии

- **Исправлена ошибка при создании сотрудника** — если логин уже занят другим сотрудником, раньше выскакивала непонятная "Internal server error"; теперь чёткое сообщение "Такой логин уже используется другим сотрудником".
- **Приёмка на "Складе" учитывает код ИКПУ** — один штрихкод в госкаталоге может быть зарегистрирован сразу под несколькими товарами (разные производители/фасовки). Теперь при сканировании такого штрихкода система показывает список всех найденных вариантов с их кодами ИКПУ, и вы выбираете нужный — вместо того чтобы система молча брала первый попавшийся.
