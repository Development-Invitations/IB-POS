### Новое в этой версии

- **Приход товара без маркировки, даже в режиме «по штрихкоду и маркировке»** — не у каждого товара в Магазине физически есть маркировка (государство вводит обязательность по категориям поэтапно, не сразу на всё). На попапе «Сколько единиц пришло по накладной?» появилась кнопка «У этого товара нет маркировки — добавить по количеству»: добавляет введённое количество в приход как обычный товар, без требования сканировать коды.
